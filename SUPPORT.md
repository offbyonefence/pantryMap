# Support

## If you need food right now

You don't need this repository — you need food, and that's okay:

- **Call 211** (or visit [211.org](https://www.211.org)) — free, confidential help
  finding food, in most languages, anywhere in the US.
- In the Dallas–Fort Worth area: the [North Texas Food Bank](https://ntfb.org/food-assistance/)
  and [Tarrant Area Food Bank](https://tafb.org/find-food/) both run "find food" locators
  covering hundreds of partner pantries.
- Or use the site this repo builds — every listing welcomes everyone.

## Using or contributing to the site

- **A listing is wrong or missing** → use the
  [Add a food bank](../../issues/new?template=add-food-bank.yml) or
  [Report incorrect info](../../issues/new?template=report-incorrect-info.yml) forms.
  No coding needed.
- **The site itself is broken** → [Bug report](../../issues/new?template=bug-report.yml).
- **You want to contribute code or data** → read [CONTRIBUTING.md](CONTRIBUTING.md).
- **Security concern** → see [SECURITY.md](SECURITY.md); please report privately.

There is no paid support and no SLA — this is a volunteer community project. Issues are
usually the fastest path to help.
